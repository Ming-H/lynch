# 问财/同花顺取数模板 · 林奇关键数字

> 对接 SKILL.md「六、关键数字」与 deep-dive「四、最终检查清单」。
> 调用方式：`python3 ~/.claude/skills/hithink-{finance|market}-query/scripts/cli.py --query "<问句>" --limit 20`
> 字段名动态，拿不到就简化问法重试（`--call-type retry`）；结构化财报数据优先走 hithink-finance Financial-API（`hithink-finance financials income/balance-sheet/cash-flow --thscode XXXXXX.SH`）。

## 分要素模板

### 估值（P/E / P/S）
```
{名称} 市盈率TTM 市净率 总市值
{名称} 所属行业 市盈率TTM          ← 同行业比较
{名称} 总市值 走营业收入            ← P/S 用市值÷年营收自算
```
- ⚠️ 历史P/E分位问财较难直接给，用"近3年市盈率区间"问法或东财F10。

### 增长（六分类判类核心）
```
{名称} 近3年净利润同比增长率
{名称} 近3年营业收入同比增长率
```
- 判类速查：净利/营收增速 <5% → 缓慢型；10–12% → 稳定型；20–25%+ → 快速增长型；大起大落 → 周期型。

### 现金与负债（财务强健度）
```
{名称} 货币资金 有息负债 资产负债率
{名称} 经营现金流净额 净利润        ← 净现比核对
```
- Financial-API 更稳：`financials balance-sheet --thscode` 取现金与负债科目。
- 每股净现金 =（货币资金 − 有息负债）÷ 总股本，为正则重新计算"实际P/E"。

### 存货（饱和/周期警报）
```
{名称} 存货 同比增长 存货周转率
```
- **连续两季存货增速 > 营收增速 = 警报**（周期型与快速增长型都适用）。

### 内部人与回购（13特征之12/13）
```
{名称} 高管增持金额
{名称} 回购 股份注销
{名称} 股东人数变化                ← 筹码集中度代理
```
- ⚠️ 增持/回购公告细节走 cninfo 或东财公告接口；甄别"作秀式"：看金额占比与是否注销。

### 机构覆盖（特征之5的反面）
```
{名称} 机构持股占流通股比例
{名称} 基金持股家数
```
- 林奇偏好机构持股**低**的冷门股（潜在买盘）；机构扎堆=故事已尽人皆知。

### 股息（缓慢增长型专用）
```
{名称} 股息率 分红总额 连续分红年数
```

## 缺口与人工项（问财覆盖不了）

| 林奇判据 | 为什么查不到 | 替代 |
|---------|-------------|------|
| 日常观察/产品体验 | 线下信息 | 用户自述 + 门店/销量公开数据 |
| 分析师覆盖家数 | 问财不稳定 | 东财 F10 盈利预测页 |
| 同店增长/门店数 | 部分公司不披露 | 财报原文"经营情况"节 |
| 隐蔽资产（土地/税损/子公司） | 非标准字段 | 年报附注逐项估算 |
| 养老金计划 | A股披露少 | 年报附注（多为国企） |
